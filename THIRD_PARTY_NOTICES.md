# Third-party dependencies

The standalone utilities in `tools/` depend on NumPy and Pillow.

Runtime dependencies:

| Dependency | Upstream | License reference |
|---|---|---|
| NumPy | https://numpy.org/ | https://github.com/numpy/numpy/blob/main/LICENSE.txt |
| Pillow | https://python-pillow.github.io/ | https://github.com/python-pillow/Pillow/blob/main/LICENSE |

Dependencies are installed separately and remain subject to their respective
licenses. No third-party source code is bundled in this release.
